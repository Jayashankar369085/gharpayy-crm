  THE ISSUE
================================================================================

Backend returns:
{
  "isDuplicate": true,
  "duplicates": [
    {
      "field": "phone",
      "value": "9876543210",
      "existingLeadId": "l-123",
      "existingLeadName": "Raj"
    }
  ]
}

Frontend was expecting:
{
  "isDuplicate": true,
  "duplicates": [
    {
      "id": "l-123",
      "name": "Raj",
      "phone": "9876543210"
    }
  ]
}

Result: Modal showed "Unknown" instead of "Raj"

================================================================================
  THE FIX
================================================================================

Added smart response format mapping to AddLeadModal.tsx

New function: mapDuplicateData(dup)

Detects response format automatically:
  • New format: { field, value, existingLeadId, existingLeadName }
  • Old format: { id, name, phone, email, budget }

Maps fields correctly:
  duplicate.existingLeadName → display as name
  duplicate.value (when field == "phone") → display as phone
  duplicate.existingLeadId → use as key

Also supports old format if it exists:
  duplicate.name → display as name
  duplicate.phone → display as phone

In DuplicateWarning component:

const mapDuplicateData = (dup: any) => {
  // New API format: { field, value, existingLeadId, existingLeadName }
  if (dup.field && dup.value) {
    return {
      id: dup.existingLeadId || dup.id || '',
      name: dup.existingLeadName || 'Unknown',
      phone: dup.field === 'phone' ? dup.value : dup.phone || '—',
      email: dup.field === 'email' ? dup.value : dup.email,
      budget: dup.budget,
      stage: dup.stage,
      area: dup.preferredArea || dup.area,
    };
  }

  // Old API format: { name, phone, email, budget, stage, preferredArea }
  return {
    id: dup.id || '',
    name: dup.name || dup.leadName || 'Unknown',
    phone: dup.phone || dup.phoneNumber || dup.phoneRaw || '—',
    email: dup.email,
    budget: dup.budget,
    stage: dup.stage,
    area: dup.preferredArea || dup.area,
  };
};

Then in the display:
const mapped = mapDuplicateData(dup);

<div className="font-semibold">{mapped.name}</div>
<div className="text-xs">{mapped.phone}</div>
