================================================================================
  API WORKFLOW
================================================================================

User Action → API Calls → List Updated

1. Click "+ Add Lead" button
   ↓
2. Modal opens with form
   ↓
3. Fill form (Name, Phone required)
   ↓
4. Click "Create Lead"
   ↓
5. POST /api/leads/check-duplicate
   └─ Returns: { isDuplicate: true/false, duplicates: [...] }
   ↓
6. If duplicate found:
   └─ Show warning modal with existing leads
   └─ User can "Cancel" or "Create Anyway"
   ↓
7. If no duplicate (or user confirms):
   POST /api/leads
   └─ Returns: { id, name, phone, ... }
   ↓
8. GET /api/leads (automatic refresh)
   └─ Returns: all leads including new one
   ↓
9. Success toast: "Lead created successfully"
   ↓
10. Modal closes
   ↓
11. New lead appears in list IMMEDIATELY
    (No page refresh needed)

================================================================================
  NETWORK TAB VERIFICATION
================================================================================

Open browser DevTools → Network tab → Filter by "localhost:3001"

You will see these API calls:

1. POST /api/leads/check-duplicate
   Status: 200 OK
   Payload: { phone: "...", email: "..." }
   Response: { isDuplicate: boolean, duplicates: [...] }

2. POST /api/leads
   Status: 201 Created
   Payload: { name, phone, email, budget, preferredArea, moveInDate, source, ... }
   Response: { id, name, phone, stage, intent, confidence, ... }

3. GET /api/leads
   Status: 200 OK
   Response: [{ ...lead1 }, { ...lead2 }, ..., { ...new_lead }]

All three calls prove the workflow is working end-to-end.
