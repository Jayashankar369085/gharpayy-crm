================================================================================
  TECHNICAL DETAILS
================================================================================

The fix handles multiple API response variations:

Response Structure 1 (Full Details):
{
  "isDuplicate": true,
  "duplicates": [{
    "name": "Raj",
    "phone": "9876543210",
    "email": "raj@example.com",
    "budget": 25000,
    "preferredArea": "Koramangala",
    "stage": "contacted"
  }]
}

Response Structure 2 (Minimal Details):
{
  "isDuplicate": true,
  "duplicates": [{
    "name": "Raj",
    "phone": "9876543210"
  }]
}

Response Structure 3 (Alternative Field Names):
{
  "isDuplicate": true,
  "duplicates": [{
    "leadName": "Raj",
    "phoneNumber": "9876543210",
    "area": "Koramangala"
  }]
}

All three structures are now handled gracefully!

================================================================================
  CODE CHANGES SUMMARY
================================================================================

BEFORE (Didn't Show Details):
```jsx
{duplicates.map((dup, idx) => (
  <div key={dup.id || idx}>
    <div>{dup.name}</div>
    <div>{dup.phone}</div>
  </div>
))}
```

AFTER (Shows All Details, Handles Missing Data):
```jsx
const dupName = dup.name || dup.leadName || 'Unknown';
const dupPhone = dup.phone || dup.phoneNumber || '—';
const dupBudget = dup.budget;
const dupStage = dup.stage;

return (
  <div key={dup.id || idx}>
    <div>{dupName}</div>
    <div>{dupPhone}</div>
    {dupBudget && <div>₹{formatBudget(dupBudget)}</div>}
    {dupStage && <div>Stage: {dupStage}</div>}
  </div>
);
```
